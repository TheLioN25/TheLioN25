### 🚀 Mi proyecto mimado
* 🐭 **[g502-profile-manager](https://github.com/TheLioN25/g502-profile-manager):**  
  Gestor de perfiles y asignación de botones para el ratón **Logitech G502 HERO** en Linux.  
  *Nació de mi propia necesidad: quería una app nativa, rápida y bonita en GTK4 para configurar mi ratón sin programas pesados. Tiene plano vectorial interactivo en Cairo, cambio reactivo de perfiles por juego y 126 pruebas unitarias.*
